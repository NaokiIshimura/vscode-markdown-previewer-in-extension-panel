# Markdown Previewer in Extension Area

VS Code のサイドバー（またはパネル）にフル機能の Markdown プレビューを常駐させ、タブ移動の手間なく執筆を続けられる拡張機能です。

## 機能一覧

| 機能名 | ショートカット | 説明 |
| --- | --- | --- |
| ヘルプ | `s` | キーボードショートカットのヘルプオーバーレイを表示。キーを押し続けると表示を維持 |
| 見出し | `h`またはホバー | 見出しパネルの表示/非表示を切り替え、またはホバーで展開。ファイルパスヘッダー内にh1-h6ナビゲーションを表示。矢印キーで項目移動、Enterで選択、Escで閉じる |
| ファイルリスト | `l`またはホバー | ファイルリストパネルの表示/非表示を切り替え、またはホバーで展開。同じディレクトリ内のMarkdownファイルを一覧表示してクイックナビゲーション。矢印キーで項目移動、Enterで選択、Escで閉じる |
| 検索 | `f` | 検索バーを表示し、大文字/小文字を区別するオプション付きで検索。Enter/Shift+Enterでマッチを移動、Escで閉じる |
| コピー | `c` | 選択したテキストをクリップボードにコピー。VS Code通知メッセージが表示される |
| ファイルパスコピー | パスクリック | ファイルパスをクリックしてクリップボードにコピー。VS Code通知メッセージが表示される |
| 引用コピー | `q` | テキストを選択した状態で`q`キーを押すと、選択したテキストの各行に `> ` を付けてコピー。Markdownでの引用に便利 |
| Light Theme<br>Dark Theme | `t` | プレビューのライト/ダークテーマを切り替え |
| Zoom In<br>Zoom Out | `+`<br>`-` | プレビューを拡大/縮小表示（現在のズームレベルを表示） |
| Reset Zoom | `r` | ズームレベルを100%にリセット |
| Navigate Previous<br>Navigate Next | `←`<br>`→` | 同じディレクトリ内の前後のMarkdownファイルに移動 |
| Pin<br>Unpin | `p` | 現在表示中のMarkdownファイルにプレビューを固定、または追従モードに戻る |
| Edit | `e` | プレビュー中のドキュメントをエディタタブで開く |
| File Path Display（ファイルパス表示） | 常時表示 | プレビュー上部にプロジェクトルートからの相対パスを表示 |
| コードブロックのシンタックスハイライト | 自動 | 言語を指定したフェンスコードブロックを色分け表示（例: <code>```javascript</code>） |
| コードブロックのコピー ボタン | ホバー操作 | フェンスコードブロック内に表示されるボタンでワンクリックコピー |
| テーマ対応スクロールバー | 自動 | プレビュー内のスクロールバーがライト/ダークテーマに合わせて着色されます |
| Open Settings | ツールバーのみ | 拡張機能の設定画面を開く |

**注意**: キーボードショートカットはプレビューにフォーカスがある時のみ動作します

## 設定項目

| 設定項目 | デフォルト値 | 説明 |
| --- | --- | --- |
| `markdownPreview.defaultZoomLevel` | `100` | デフォルトのズーム率を設定（50–200） |
| `markdownPreview.themeMode` | `auto` | プレビューのテーマモード（`auto`, `light`, `dark`） |

## 動作条件
- Visual Studio Code 1.74.0 以降
- 現在のワークスペース内にある Markdown ファイル（`.md`）

## 開発
```bash
npm install      # 依存関係のインストール
npm run compile  # ./out への単発ビルド
npm run watch    # 開発中の継続ビルド
```
VS Code の拡張機能開発ホスト（F5）を起動すると、新しいウィンドウで変更を即座に確認できます。

## ヒントと既知の制限
- ファイル一覧パネルは現在のファイルと同じディレクトリ内の全Markdownファイルを表示し、現在のファイルがハイライト表示されます。
- `l`キーでファイル一覧を切り替えるか、ヘッダーの「Files」にマウスカーソルを合わせます。任意のファイルをクリックして切り替えることができます。
- 見出しパネルは Markdown ドキュメントから h1-h6 見出しを自動的に抽出し、クリック可能なナビゲーションを提供します。
- 見出しパネルはプレビュー上部のファイルパスヘッダー内に配置されています。
- 見出しタイトルにマウスカーソルを合わせるとナビゲーションドロップダウンメニューが展開されます。
- ドロップダウン内の見出しをクリックすると、プレビュー内のそのセクションまでスムーズにスクロールします。
- ファイルリストパネルは同じディレクトリ内の他の Markdown ファイルを表示し、クイックナビゲーションを提供します。
- ファイルリストパネルは、ディレクトリ内に2つ以上の Markdown ファイルがある場合にのみ表示されます。
- ファイルリストドロップダウン内のファイル名をクリックすると、そのファイルのプレビューに切り替わります。
- 見出しパネルまたはファイルリストパネルが開いている時、矢印キー（↑/↓/←/→）で項目を移動、Enterで選択、Escで閉じることができます。
- 左右矢印キー（←/→）で同じディレクトリ内の前後のMarkdownファイルに移動できます。
- Mermaid 図は jsDelivr CDN から読み込むため、オフライン環境では描画されません。
- 画像やリンクは VS Code のワークスペースパス解決を利用します。参照先ファイルが到達可能な場所に存在することを確認してください。
- Markdown ファイルが開かれていない場合、利用可能であればワークスペースの README.md を自動的に表示します。
- 非 Markdown ファイルに切り替えてもプレビューは継続されるため、コード作業中もドキュメントを表示し続けることができます。
- 別の Markdown ファイルに切り替えた際、スクロール位置が自動的に最上部にリセットされ、新鮮な閲覧体験を提供します。
- 引用コピー機能は、Issue やプルリクエスト、その他の Markdown ドキュメントでコンテンツを引用する際に便利です。
