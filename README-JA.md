# Markdown Previewer in Extension Area

VS Code のサイドバー（またはパネル）にフル機能の Markdown プレビューを常駐させ、タブ移動の手間なく執筆を続けられる拡張機能です。

## 主な特徴
- アクティブなエディタに追従する常設 Markdown プレビュー。必要に応じて関心のあるファイルへピン留め可能
- ライブ更新とテーマ連動スタイルに加え、手動でライト/ダークを切り替えて見た目を強制変更
- ズームイン/アウト/リセットとデフォルトズーム（50〜200%）の永続設定
- ビュー内のツールバーから `Edit`、`Refresh`、`Pin/Unpin`、`Open Settings`、ズーム/テーマ操作をワンクリックで実行
- キーボードショートカットで効率的な操作が可能：
  - 左右の矢印キーでフォルダ内のMarkdownファイルを移動（ピン留め時も動作）
  - `p` キーでピン留めの切り替え
  - `e` キーでプレビュー中のファイルをエディタで開く
  - `+` キーでズームイン
  - `-` キーでズームアウト
  - `r` キーでプレビューを更新
- Mermaid 図のレンダリングやワークスペース相対パスを考慮した画像解決ロジックを搭載
- サイドバー表示とパネル表示を切り替えられ、用途に合わせて柔軟にレイアウト

## 動作条件
- Visual Studio Code 1.74.0 以降
- 現在のワークスペース内にある Markdown ファイル（`.md`）

## 使い方
1. 任意の Markdown ファイルを開くと、「Markdown Preview」ビューが自動で起動し内容を表示します。
2. エディタで編集を続けると、プレビューもリアルタイムに同期して更新されます。別の Markdown ファイルへ移動するとプレビューも追随します。
3. ピン留めボタンまたは `p` キー（プレビューがフォーカスされている時）を押すと、現在プレビュー中のファイルを固定できます。操作の確認メッセージが表示されます。
4. プレビュー対象と編集中のファイルが異なるときは、`e` キーまたは `Edit` ボタンで対象ファイルのエディタへすぐに戻れます。
5. 矢印キー（`←` / `→`）でMarkdownファイル間を移動できます。ピン留め時でも動作し、確認メッセージが表示されます。
6. `+` と `-` キーまたはツールバーのボタンでズーム調整ができます。ズーム時には現在のズームレベルが表示されます。
7. `r` キーまたは `Refresh` ボタンで強制的に再描画できます（外部ツールでの変更反映やMermaid図の再描画が必要な場合など）。

### ビューのツールバーコマンド
- `Edit [e]` — プレビュー中のドキュメントをエディタで開き直します（現在別のファイルを見ているときのみ表示）。
- `Pin [p]` / `Unpin [p]` — 現在の Markdown ファイルにプレビューを固定、または追従モードに戻します。確認メッセージが表示されます。
- `Use Light Theme` / `Use Dark Theme` — プレビュー側だけを手動でライト/ダーク表示へ切り替えます。
- `Zoom In [+]`、`Zoom Out [-]`、`Reset Zoom` — 表示倍率を調整し、リセットすると既定値（設定で変更可）に戻ります。現在のズームレベルが表示されます。
- `Refresh [r]` — Markdown を強制再レンダリングします。
- `Open Settings` — 拡張機能の設定項目へジャンプします。

### キーボードショートカット（プレビューがフォーカスされている時）
- `←` / `→` — 現在のディレクトリ内の前後のMarkdownファイルへ移動（ピン留め時も動作）
- `p` — ピン留めの切り替え
- `e` — プレビュー中のファイルをエディタで開く
- `+` — ズームイン（現在のズームレベルを表示）
- `-` — ズームアウト（現在のズームレベルを表示）
- `r` — プレビューを更新

### 設定項目
- `markdownPreview.defaultZoomLevel` — 既定のズーム倍率を 50〜200 の範囲で指定（デフォルトは 100）。
- `markdownPreview.themeMode` — プレビューのテーマモードを `auto`、`light`、`dark` から選択。

## 開発
```bash
npm install      # 依存関係のインストール
npm run compile  # ./out への単発ビルド
npm run watch    # 開発中の継続ビルド
```
VS Code の拡張機能開発ホスト（F5）を起動すると、新しいウィンドウで変更を即座に確認できます。

## ヒントと既知の制限
- Mermaid 図は jsDelivr CDN から読み込むため、オフライン環境では描画されません。
- 画像やリンクは VS Code のワークスペースパス解決を利用します。参照先ファイルが到達可能な場所に存在することを確認してください。
- 非 Markdown ファイルをアクティブにしている間は、ビューに案内メッセージを表示します。
